## Pipeline Fix: Intro-Dedup (Step 1c)

Robert asked why Keith Mabry's review wasn't auto-removed from the Gardette/Gigondas email. Root cause: the pipeline's auto-remove logic (Step 1b) only fires when NO intro is provided. When Murray explicitly provided Keith's text as the `Intro:` field, Step 1b was skipped entirely.

**Fix:** Added Step 1c to `pipeline.js` — after Step 1b, when an explicit intro IS provided for single-SKU emails, compares intro text against each review in the wine block. If match detected (first 100 chars after HTML entity decoding), auto-injects CustomEdit instruction to remove the duplicate review.

Key detail: had to add `&#NNN;` numeric entity decoding (e.g. `Rh&#244;ne` → `Rhône`) for the text comparison to work.

Re-tested both:
- Gardette: Keith's review auto-removed ✅ (10 actions, CustomEdit auto-injected)
- Ontañón: No false positive ✅ (intro is winery description, not a review)
